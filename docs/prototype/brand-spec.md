# SigmaMentor · 品牌规范（brand-spec）

> 来源：`sigmentor-deck.html`（Ink Classic 主题，项目内唯一品牌源）。
> 基础色逐字照抄源文件 hex，不做目测近似；派生色一律由 `oklch()` 低彩度生成。
> 适用于本项目全部原型屏幕（学生端 / 教师端 / 启动页）。

## 一、六 token

| Token | 值 | 说明 |
|---|---|---|
| `--bg` | `#f1efea`（paper） | 内容区底色；暗色场景反转见下 |
| `--surface` | `#f8f6f2` | 卡片面（由 paper 提亮一档） |
| `--fg` | `#0a0a0b`（ink） | 正文/标题前景；暗色场景作底色 |
| `--muted` | `rgba(10,10,11,.62)` | 次级文字（ink 透明度阶梯，不用灰 hex） |
| `--border` | `rgba(10,10,11,.16)` | 发丝线；强线 `rgba(10,10,11,.55)` |
| `--accent` | `oklch(0.45 0.10 262)` | 蓝墨水——仅激活态/链接/焦点环，每屏 ≤2 处显著使用 |

### 双端主题（用户指定，2026-08-15 追加）

全站用**顶部导航栏**（无侧栏），两端以主题区分：

- **学生端 · 墨黑**（`body.theme-dark`）：页面底 `#0d0d0e`，卡片面 `#17171a`，次级面 `#232327`，前景 `#f1efea`，发丝线 `rgba(241,239,234,.14–.58)`，accent 提亮为 `oklch(0.70 0.09 250)`，导航底 `#0d0d0e`。
- **教师端 · 中性灰**（`body.theme-gray`，默认）：页面底 `#ececea`，卡片面 `#f7f7f5`，次级面 `#e3e3e1`，导航底 `#26262a`（炭灰）。
- **总览页**：浅色纸面自成一页，链向两端。

实现方式：`app.css` 顶部主题层用 body 类成对互换 `--paper/--ink/--surface/--line…` 变量，组件规则只引用变量即自动适配；字面量颜色在各页 `.theme-dark` 补丁块集中维护。

### 语义色（数据专用，oklch 低彩度，编辑风格）

| 语义 | 值 | 用途 |
|---|---|---|
| 通过 | `oklch(0.52 0.10 155)` | 判题通过 / 通过率 |
| 部分/警告 | `oklch(0.60 0.11 75)` | 部分通过 / 放弃 / 趋势上行（配深字） |
| 失败 | `oklch(0.52 0.14 28)` | 编译错 / 运行错 / 未通过 |
| 热力梯度 | `rgba(10,10,11,.05→.86)` 五档 | 热力图 / 缺陷条，不引入彩色 |

## 二、字体栈（照抄 deck，Google Fonts 引入）

- **Display（中文标题）**：`"Noto Serif SC", source-han-serif-sc, serif` — 权重 600/700
- **Display（西文/数字）**：`"Playfair Display", "Source Serif 4", Georgia, serif` — 统计数字 800 + `tnum`
- **Body**：`"Noto Sans SC", source-han-sans-sc, sans-serif`
- **Mono（标签/数据/代码）**：`"IBM Plex Mono", ui-monospace, monospace`

## 三、视觉规则（从 deck 观察提炼）

1. **黑白双色制**：ink/paper 主导一切界面；彩色只出现在数据语义（对/错/警）与蓝墨水激活态，绝不做装饰性渐变。
2. **mono 大写宽字距标签层**：栏目、页眉、表头、徽标一律 `letter-spacing .18–.26em` + `text-transform: uppercase` + 小号（10–11px），构成杂志式导航骨架。
3. **发丝线代替阴影**：分隔与容器用 1px 低透明度 ink 线 + 近直角（3px）；双规则线（上下 2px）保留给红线/宣言横幅。
4. **透明度做层次**：文字层级靠字号 + 字重 + ink 透明度阶梯（.45/.62/.82/1），不加底色块。
5. **数字用衬线**：一切统计数字用 Playfair Display + 表格数字变体，标题用 Noto Serif SC——数据即版面主角。

## 四、一句话总结

黑白编辑杂志语言移植为产品界面：墨色侧栏 + 纸色版面 + 发丝线卡片，mono 标签做骨架、衬线数字做主角，彩色只服务数据语义。
