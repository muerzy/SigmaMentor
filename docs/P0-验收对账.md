# PRD §4.2 P0 验收对账清单（2026-08-16 实测）

> 实测环境：Windows 11 · Bun 1.3.14 · SQLite · 三端本地运行 + Chrome 浏览器全链路操作
> 测试基线：`bun test` 60/60 通过 · `bun run lint` 0 error · `bun run fmt:check` 通过

## F1 作业提交与沙箱判题

| 验收标准 | 结果 | 证据 |
|---|---|---|
| 1. 一次提交 ≥1 条事件，间隔误差 <1s | ✅ | API 测试断言客户端事件 `at` 与入库误差 <1000ms；浏览器实测编辑/放弃/判题事件实时入列（间隔显示 +40秒 等真实值） |
| 2. 判题结果与标准答案用例集一致（10 题 × 5 用例回归） | ✅ | `services/sandbox/sandbox.test.ts` 10 题回归：标准解全部 pass、错误解全部非 pass；浏览器实测 i<=n → partial 1/5、i<n → pass 5/5 |
| 3. 沙箱超时/死循环被终止，不影响下一次执行 | ✅ | 沙箱测试：死循环 1200ms 被 kill → 紧接正常提交 pass |
